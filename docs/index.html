Chrome 内蔵の Gemini Nano が、開いている日本語ページの段落を ひとつずつ英訳します。CEFR B2 以上の単語の下にだけ、小さく 日本語のルビが添えられるので、読み進める手が止まりません。 通信なし、保存なし、すべて端末内。

02 — Features

派手な機能は、ない。読むためだけの三つ。

  • i.

    ローカル処理、
    外部送信ゼロ。

    翻訳は Chrome 内蔵の Gemini Nano が端末内で行います。本文も翻訳結果も、 拡張のソースコードに fetch も XMLHttpRequest も書かれていない以上、外に出る経路がありません。

  • ii.

    難単語のみ、
    ルビ表示。

    CEFR B2 以上の語、つまり大学入学共通テスト水準を超える語にだけ 日本語訳が付きます。基本語にはルビが付かないので、知っている語の 読み流しが止まりません。

  • iii.

    サイトごとに、
    自動実行 ON/OFF。

    「Wikipedia は自動翻訳、Google 検索結果は触らない」のような使い方が そのまま設定できます。ホストごとに状態が独立しているので、 いつ・どこで翻訳が走るかが常に明示的。

03 — Requirements

動作要件

Browser
Google Chrome 140 以降（デスクトップ版）
OS
macOS 13+ / Windows 10+ / Linux / ChromeOS（Chromebook Plus）
Storage
22 GB 以上の空き容量（モデル本体の保存先用）
GPU / RAM
VRAM 4 GB 以上の GPU、または 16 GB 以上の RAM + 4 コア以上の CPU
Network
初回のモデルダウンロード時のみ必要（メータリング接続不可）
Permissions
storage · activeTab · scripting のみ。tabs・cookies・history などは要求しません。
04 — Install

開発版（unpacked）の入れ方

Chrome Web Store 公開前のため、現在は開発者モードでの読み込みになります。

  1. リポジトリをクローン: git clone https://github.com/enumura1/furigana-en.git

  2. Chrome で chrome://extensions/ を開き、 右上の「デベロッパーモード」を ON。

  3. 「パッケージ化されていない拡張機能を読み込む」 を押し、クローンしたディレクトリ（manifest.json がある階層）を選択。

  4. ツールバーにアイコンをピン留め。日本語ページを開いて 「このページで実行」を押すと翻訳が始まります。 初回はモデルのダウンロードが走ることがあります。
