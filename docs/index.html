EN Gloss Reader v0.1.0

日本語のページを英語で読む。
むずかしい単語の下に、小さく日本語訳。

Chrome 内蔵の Gemini Nano が、開いている日本語ページを段落ごとに 英語へ翻訳します。英検準1級・大学入試レベルを超えるような単語にだけ、 小さな日本語訳を添えるので、知らない単語で読みが止まりません。 翻訳はすべて端末内で行われ、ページ本文も翻訳結果も外部に送られません。

こうなります

日本語のページに拡張を効かせると、本文がこのように置き換わります。 動詞はピンクに、知らない可能性のある単語の下には小さく日本語訳が出ます。

日本語のページ

深層学習は近年、画像認識や自然言語処理の分野で、めざましい発展を遂げてきた。

↓
拡張をオンにすると

Deep learning has achieved達成した remarkableめざましい progress in image recognition and natural language processing in recent years.

ピンクの単語 = 動詞 単語の下の小さな字 = 日本語訳

3 つの特徴

すべて端末内で処理

翻訳は Chrome 内蔵の Gemini Nano が端末のなかだけで動かします。 ページ本文も翻訳結果も外部サーバには送信されません （ソースコードに fetch も XMLHttpRequest も書かれていません）。

むずかしい単語にだけ日本語訳

基本語にはなにも添えません。英検準1級・大学入試レベルを超えるような単語の下にだけ、 小さな日本語訳がつきます。知っている単語で読みが止まりません。

サイト単位で自動翻訳の ON/OFF

「Wikipedia は自動で翻訳、Google 検索結果は触らない」のような設定が、 ホストごとに独立してできます。意図しないページが勝手に書き換わることはありません。

VRAM 4 GB 以上の GPU、または RAM 16 GB 以上 + 4 コア以上の CPU
ネットワーク
初回モデルダウンロード時のみ必要

使い方

現在は Chrome Web Store 公開前のため、開発者モードで読み込みます。

  1. リポジトリをクローン:
    git clone https://github.com/enumura1/furigana-en.git
  2. chrome://extensions/ を開いて、 右上の「デベロッパーモード」を ON。
  3. 「パッケージ化されていない拡張機能を読み込む」を押して、 クローンしたフォルダ（manifest.json がある階層）を選択。
  4. ツールバーにアイコンをピン留めし、日本語のページを開いて 「このページで実行」を押すと翻訳が始まります。 初回はモデルのダウンロードが走ります（数分〜十数分）。
