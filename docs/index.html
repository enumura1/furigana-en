開いている日本語ページを、Chrome 内蔵の Gemini Nano が段落ごとに英語へ翻訳します。 難しい単語の下にだけ小さく日本語訳が添えられるので、知らない単語で読みが止まりません。 翻訳はすべて端末内で行われ、ページ本文も翻訳結果も外部に送られません。

Features

特徴

端末内ですべて処理

翻訳は Chrome 内蔵の Gemini Nano が端末内で実行します。ページ本文も翻訳結果も外部サーバには送信しません。

難しい単語にだけ訳

基本語には何も付けません。英検準1級・大学入試レベルを超える単語にだけ、小さな日本語訳が添えられます。

サイト単位で自動実行

ホストごとに自動翻訳を ON/OFF できます。Wikipedia は自動で、検索結果はそのまま、といった切り分けが可能です。

Install

使い方

現在は Chrome ウェブストア未公開のため、開発者モードで読み込みます。

  1. リポジトリをクローン: git clone https://github.com/enumura1/furigana-en.git
  2. chrome://extensions/ を開き、右上の「デベロッパーモード」を ON にします。
  3. 「パッケージ化されていない拡張機能を読み込む」を押し、クローンしたフォルダ（manifest.json がある階層）を選択します。
  4. 日本語ページを開き、ツールバーのアイコンから「このページで実行」を押します。初回はモデルのダウンロードが入ります。
